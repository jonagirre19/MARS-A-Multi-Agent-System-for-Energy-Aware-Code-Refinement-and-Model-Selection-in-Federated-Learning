File Descriptions

Python Files (.py)

File: client_app.py
The provided client_app.py file defines a Flower ClientApp for a federated learning system using PyTorch, specifically tailored for training and evaluating a neural network on the MNIST dataset. It implements two core methods: train and evaluate, which are invoked by the Flower framework during federated training rounds. The train function loads a model, applies global weights from the server, trains the model on local data partitioned by the client's configuration, saves the updated model state to the client’s local storage, and returns the updated weights along with training metrics. The evaluate function loads the model with global weights, evaluates it on a local validation set, and returns evaluation metrics such as loss and accuracy. The client also manages model persistence via save_model_to_state and load_model_from_state functions, enabling optional local state retention between training rounds. This setup allows clients to participate in federated training while maintaining their own data locally and communicating only model updates and metrics to the central server.

File: server_app.py
This file defines the main server application for a federated learning system using the Flower framework, specifically tailored for a PyTorch-based MNIST classification task. It initializes and configures the federated training process by setting up the server environment, loading the global model, defining a custom strategy (CustomStrategy) for federated averaging, and managing the training rounds. The application reads configuration parameters such as the number of rounds, training/fraction evaluation ratios, and device settings from the context. It also handles the global evaluation function that assesses model performance on a centralized test dataset after each round, aggregating results from multiple .npz files containing test data. Finally, it saves the final trained model weights to disk after completing all rounds of federated training.

File: strategy.py
This file defines a custom federated learning strategy named CustomStrategy that extends the standard FedAvg algorithm from Flower. Its primary purpose is to enhance the basic federated averaging process by adding functionality for saving model checkpoints, logging metrics to Weights & Biases (W&B), and persisting results to disk. The strategy overrides key methods such as configure_train to implement a simple learning rate schedule, and implements custom logic in start to manage training rounds, evaluate performance, and handle result aggregation. It also includes helper functions to update the best model based on accuracy and save evaluation metrics in JSON format after each round. This allows for comprehensive tracking and analysis of the federated learning process, including model persistence and experiment monitoring.
