# 🤖 MARS: A Multi-Agent System for Energy-Aware Code Refinement and Model Selection in Federated Learning.

This repository stores the experimental results, performance artifacts, hardware metrics, and generated models produced by the multi-agent system proposed in the paper **MARS: A Multi-Agent System for Energy-Aware Code Refinement and Model Selection in Federated Learning**.

Rather than containing the agent source code, this repository serves as a centralized record of experimental results for federated learning, tracking project analyses, model recommendations, dynamic strategy evolutions, and resource-aware optimizations using the **Flower** framework and **PFLlib** backbones.

# 📂 Repository Structure & Architecture

The repository is structured around different LLM testing pipelines, benchmark datasets, and execution phases.

```text

.
├── Gemma4/                                      # Tests conducted using LLM Provider 1
│   ├── DNN-MNIST/                               # Deep Neural Network experiments on MNIST
│   │   └── {id}-dnn_mnist_example-{distribution}/
│   │       ├── train/                           # Training dataset split
│   │       ├── test/                            # Test dataset split
│   │       ├── client_app.py                    # Flower federated learning client implementation
│   │       ├── server_app.py                    # Flower federated learning server implementation
│   │       ├── strategy.py                      # Base FedAvg strategy (from PFLlib)
│   │       ├── {strategy_name}_strategy.py      # Dynamically developed custom strategies
│   │       ├── rag_report.html                  # Report comparing baseline vs. Phase 1 and Phase 3 best models
│   │       └── ProjectDevelopment/              # Agent outputs and phase tracking
│   │           ├── project_analysis.txt         # Analysis of the project
│   │           ├── model_recommendations.json   # Phase 1 model recommendations
│   │           ├── resource_aware_model_recommendations.json # Phase 3 resource-aware recommendations
│   │           └── {strategy_folder}/          # Strategy-specific execution directories
│   │               ├── results_base_strategy/  # Baseline strategy execution
│   │               └── results_{custom_strategy}_strategy # Agent-developed strategy execution
│   │                   ├── task_final.py       # Final developed model script
│   │                   ├── client_eval_metrics.json # Client-side evaluation metrics
│   │                   └── metrics_{device}.json # Device resource metrics (CPU usage, temperature, etc.)
│   └── MLR-MNIST/                               # Multinomial Logistic Regression experiments on MNIST
│
└── Qwen3.6/                                     # Tests conducted using LLM Provider 2


```

# 📊 Key Artifacts & Metrics

| Artifact / File | Description |
|---|---|
| `rag_report.html` | Visual summary report comparing the baseline model against the Phase 1 performance model and Phase 3 efficient model, including a breakdown of the Flower project structure. |
| `client_eval_metrics.json` | Detailed evaluation metrics collected from each federated client. |
| `metrics_{device}.json` | Hardware telemetry tracking device resource consumption (e.g., average CPU usage and temperature). |
| `project_analysis.txt` | Initial project analysis generated by the multi-agent system. |
| `model_recommendations.json` | Agent-generated architecture recommendations for Phase 1. |
| `resource_aware_model_recommendations.json` | Agent-generated recommendations for resource-constrained models in Phase 3. |
